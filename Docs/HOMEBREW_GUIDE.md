# Homebrew Distribution Guide 🍺

This guide walks you through setting up a **Homebrew Tap** so anyone on macOS can install **Offload** with a single command:

```bash
brew install --cask iperamuna/tap/offload
```

Homebrew automatically detects whether the user's Mac runs on **Apple Silicon (M1/M2/M3/M4)** or **Intel (x86_64)**, downloading and installing the matching native build automatically!

---

## 📋 Overview: Two Distribution Methods

| Method | Setup Effort | Approval Required | Best For |
| :--- | :--- | :--- | :--- |
| **1. Personal Tap (`iperamuna/homebrew-tap`)** *(Recommended)* | 5 minutes | None (Instant) | Full release control, instant updates, auto-arch detection |
| **2. Homebrew Core (`homebrew/homebrew-cask`)** | PR review | Yes (Homebrew team) | Widespread public discovery (after achieving 30+ GitHub stars) |

---

## Method 1: Creating Your Personal Tap (Recommended)

Homebrew allows creating your own "Tap" repository on GitHub. Once created, users can install your app directly via `brew install --cask iperamuna/tap/offload`.

### Step 1: Create the Tap Repository on GitHub

1. Go to [github.com/new](https://github.com/new).
2. Set the repository name to:
   ```text
   homebrew-tap
   ```
   *(Homebrew requires the repository name to follow the convention `homebrew-<name>`, so `homebrew-tap` lets users refer to it as `iperamuna/tap`).*
3. Set visibility to **Public**.
4. Check **Add a README file** and create the repository.

---

### Step 2: Clone the Tap Repository Locally

```bash
git clone https://github.com/iperamuna/homebrew-tap.git
cd homebrew-tap
mkdir -p Casks
```

---

### Step 3: Create the Multi-Arch Cask Formula (`Casks/offload.rb`)

Inside `homebrew-tap`, create the file `Casks/offload.rb`:

```ruby
cask "offload" do
  arch arm: "Apple_Silicon", intel: "Apple_Intel"

  version "1.0.0"
  sha256 arm:   "e27088ecdc89da20a2e00cbcdad2d37c85fa0bf02bbfcbda074c5157e793d832",
         intel: "63b4a0157861c2ad3c09b26090a4052201ad4feef97fa5c825d1f4f09c62ab1e"

  url "https://github.com/iperamuna/offload/releases/download/v#{version}/Offload_#{version}_#{arch}.dmg"
  name "Offload"
  desc "Smart macOS drive space offloader and symlink manager"
  homepage "https://github.com/iperamuna/offload"

  livecheck do
    url :url
    strategy :github_latest
  end

  auto_updates true
  depends_on macos: :monterey

  app "Offload.app"

  zap trash: [
    "~/.offload-internal",
    "~/Library/Application Support/com.indunilperamuna.offload",
    "~/Library/Preferences/com.indunilperamuna.offload.plist",
    "~/Library/Saved Application State/com.indunilperamuna.offload.savedState",
  ]
end
```

> **How this works**: Homebrew queries the user's CPU. If `arm` (Apple Silicon), it substitutes `arch = "Apple_Silicon"` and checks the `arm` SHA256. If `intel`, it substitutes `arch = "Apple_Intel"` and checks the `intel` SHA256. Zero user configuration required!

---

### Step 4: Add the SHA-256 Checksums

From the GitHub Release artifacts, grab the SHA-256 hashes generated by GitHub Actions:
- `Offload_1.0.0_Apple_Silicon.dmg.sha256`
- `Offload_1.0.0_Apple_Intel.dmg.sha256`

Place them into the `sha256 arm: ..., intel: ...` block in `Casks/offload.rb`.

---

### Step 5: Commit and Push the Tap

```bash
git add Casks/offload.rb
git commit -m "feat: add offload v1.0.0 multi-arch cask"
git push origin main
```

---

### Step 6: Test Installation on Any Mac

Now anyone can install Offload with:

```bash
# 1-step install (automatically picks the correct architecture):
brew install --cask iperamuna/tap/offload
```

To upgrade in the future:
```bash
brew upgrade --cask offload
```
